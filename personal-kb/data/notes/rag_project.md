# Personal Knowledge Base

I am building a Personal Knowledge Base with RAG.

The project uses LlamaIndex for document ingestion and retrieval.

Qdrant is used as the vector database.

Ollama is used for local LLM inference and embeddings.

The system should eventually support temporal queries.

I want to ask questions such as:

"What did I decide about a project last March?"

The system should retrieve the relevant historical information and provide grounded answers.
